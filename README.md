# NEXORA®

Адаптивный сайт на React, TypeScript и Vite. Без backend, внешних API и тяжёлых библиотек.

## Запуск

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Проверка TypeScript: `npm run typecheck`.
Просмотр сборки: `npm run preview`.

## Настройка почты

Укажите настоящий адрес в `src/config.ts` (`CONTACT_EMAIL`). Без адреса форма проверяет поля и честно сообщает, что отправка недоступна. После настройки она предлагает открыть подготовленное письмо через mailto. Пользователь отправляет письмо самостоятельно.

## Медиа

Исходный MP4 воспроизводится автоматически, без звука и с обычным циклом. FFmpeg в среде отсутствовал; прямой/обратный цикл не создан. JavaScript не эмулирует обратное воспроизведение.

Названия входных изображений расходятся с их содержимым: nexora-poster.png содержит макет с надписями, nexora-reference.png — чистую сцену. Чистая сцена оптимизирована в JPEG (310 КБ вместо 1,7 МБ) и сохранена в public/media/nexora-poster.jpg для резервного фона без дублирования интерфейса. При reduced motion и ошибке видео показывается этот фон.

Демонстрация — условная визуализация, не измерение эффективности. Данные формы не сохраняются на сервере. Контакты, клиенты, показатели и отзывы не выдуманы.
